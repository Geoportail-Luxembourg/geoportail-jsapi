About Topology API

The Topology API provides reusable geometry and topology operations for working with polygon features in web mapping applications. It includes functions for detecting topological relationships, merging and splitting features, and maintaining topological consistency during editing.

Key Features:

  • Boundary Detection: Find which features share a boundary
  • Feature Merging: Combine multiple features into one using JSTS
  • Feature Splitting: Divide a feature with a line geometry
  • Overlap Detection: Identify intersecting features
  • Vertex Propagation: Automatically sync shared vertices across boundaries
  • Hole Insertion: Create holes/donuts in polygon features

Usage in Your Application

import lux from 'lux-jsapi';
import OL3Parser from 'jsts/io/OL3Parser.js';
import 'jsts/monkey.js';

// Create JSTS parser
const jstsParser = new OL3Parser();

// Find topological neighbors
const neighbours = lux.topology.findTopologicalNeighbours(
  jstsParser,
  feature,
  allFeatures,
  { vertexPrecision: 2 }
);

// Merge features
const result = lux.topology.mergeFeatures(jstsParser, [feature1, feature2]);

// Detect overlaps
const overlaps = lux.topology.checkOverlapsNeighbours(
  jstsParser,
  feature,
  allFeatures,
  0.01
);

// Propagate shared vertices
const changed = lux.topology.propagateSharedVertices(
  modifiedFeature,
  allFeatures,
  { vertexPrecision: 2 }
);
